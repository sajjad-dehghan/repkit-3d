# RepKit 3D

**21 free gym, fitness and bonus lifestyle icons.** Warm yellow and orange accents, dark materials, and transparent backgrounds.

![RepKit 3D preview](linkedin/slides/01.png)

**[Download the pack](https://github.com/sajjad-dehghan/repkit-3d/archive/refs/heads/main.zip)** · [Browse the PNG files](Gym-Fitness-Icons) · [LinkedIn carousel](linkedin/RepKit-3D.pdf)

## What's included

- 21 individual PNGs, each **1254 × 1254 px**, with alpha transparency.
- Gym equipment, weights, cardio accessories, a sports bottle, and two bonus lifestyle icons.
- A local gallery: download the repository and open `Gym-Fitness-Icons/index.html`.
- A six-slide Persian LinkedIn carousel in PDF, editable PowerPoint, and 1080 × 1080 PNG pages.

The assets are AI-generated raster illustrations with a 3D appearance. Editable 3D models are not included. The PowerPoint uses Arial and [Vazir](https://github.com/rastikerdar/vazir-font); use the PDF or PNG pages for the fixed layout.
